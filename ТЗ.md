# Техническое задание: Программа для приветствия пользователей и создания профилей

## 🎯 Цель
Создать программу на Python, которая:
1. Приветствует пользователя по ФИО
2. Проверяет наличие пользователя в существующих README файлах
3. Предлагает заполнить метрики (данные) для новых пользователей
4. Создает новые README файлы для новых пользователей

## 📋 Требования к функционалу

### 1. Ввод данных
- Программа запрашивает у пользователя ввод ФИО (Фамилия Имя Отчество)

### 2. Проверка существующего пользователя
- Программа проверяет наличие введенного ФИО в существующих README файлах
- Поиск осуществляется в файлах с расширением `.md` в текущей директории

### 3. Логика работы
- Если пользователь найден в существующих файлах: выводится приветствие
- Если пользователь не найден: выводится приветствие и предлагается заполнить данные

### 4. Заполнение метрик для новых пользователей
Для новых пользователей запросить:
- **Курс**
- **Группу**
- **Специальность**
- **Код специальности**
- **Название практики**
- **Номер команды**

### 5. Создание README файла
- Для нового пользователя создать файл в формате `README_Фамилия_Имя.md`
- Файл должен содержать заголовок с ФИО и все введенные метрики в структурированном виде
